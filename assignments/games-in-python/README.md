
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo da forca em Python para praticar manipulação de strings, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição

Desenvolva um jogo em que o jogador adivinha as letras de uma palavra oculta antes de esgotar as tentativas disponíveis.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso da palavra no formato `_ _ _`.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
